# P2 · Story Plan

*P2 加载：story-craft-and-canon、reference-input-policy。*

给 2–3 个原创方向，形成 Hook → Setup → Escalation → Turning Point → Payoff → Ending 的稳定 node、情绪曲线和场景预算。Reference 规则必须经过原创改造。

输出 schema：selected concept、nodes、cause-effect chain、character state transitions、emotion curve、scene budget、adopted/rejected rules、approval。

Hard Stop：方向必须由用户/预授权策略选定；FAST 可 REVIEW，GUIDED/STRICT 为 HARD。不得自动进入 P3。
