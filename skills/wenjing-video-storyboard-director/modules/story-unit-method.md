# Story Unit Method

层级：`sequence → beat → shot`。

- sequence：同一场景/时间连续段或清晰转场单元；有入口状态、出口状态与 Script refs。
- beat：一个叙事功能或状态变化，如 setup、reveal、reaction、decision、knowledge delivery、payoff。
- shot：为表达 beat 和 action atoms 所需的最小摄影单元。

切分依据为场景、时间、因果、叙事转折和动作可完成性，不按固定秒数或台词行机械切。每个 Script beat 恰有 coverage；重复覆盖要说明功能，缺失即 FAIL。
