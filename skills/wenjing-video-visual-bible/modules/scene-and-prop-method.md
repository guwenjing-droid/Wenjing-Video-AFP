# Scene & Prop Reference Method

## 场景

核心场景至少记录：空间边界、入口/出口、关键区域、固定陈设、主要光源/时间状态、角色尺度参照、可变与不可变项。正反向/侧向/俯仰视图按下游实际覆盖选取，不全角度生成。

场景 reference 是空间事实，不是逐镜构图。禁止写镜号、焦段、运镜和剪辑节奏。

## 道具

关键道具记录：形状、材质、比例、颜色、独特标志、持有者/默认位置、Script 中的状态变化及 evidence。跨场变化用状态链，不创建互不相干的新 ID。

## 生成、复用与失败

沿用公共授权、rights、version、hash 与 readiness 规则。已有资产兼容即复用。失败以 scene/prop asset_id 或具体 view 为重跑单位，不影响无依赖资产。
