# P2 · Narrative Reverse Engineering

> 只逆向分析怎么讲，不改写为新主题故事，也不生成成品剧本。

## 执行

1. Read `modules/narrative-engagement-methods.md` 与 Evidence policy。
2. 按可观察材料定位 Hook、Setup、Escalation、Turning Point、Payoff、Ending；缺失项写 `NOT_PRESENT`。
3. 为每个结构单元登记范围、功能、前后转换和 Evidence Anchor。
4. 绘制情绪推进，只描述材料中可见/可听的变化；不把预期观众情绪写成已发生事实。
5. 判断主结构（如问题→原因→方案），说明连贯处、断层和证据。

## 完成标准

- 结构角色与实际内容对应，不为凑六段虚构单元。
- transcript-only 只依据文本次序和语言结构，不声称实际剪辑节奏。
- 所有判断有锚或明确 ANCHOR_LIMITED。

## 输出 schema 与落盘

更新 DRAFT 的 Narrative Reverse Engineering 与 Evidence Anchors，更新 state。

## Hard Stop

```text
╭─ Reference Analyzer · P2 完成 ─╮

```

不自动进入 P3。

## 反模式

- 把所有视频硬套同一结构；从 transcript 推断镜头长度；把“可能有效”写成真实留存因果。
