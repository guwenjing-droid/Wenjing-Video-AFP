# P2 · Scene Architecture

> 只把 Narrative Nodes 映射为场次功能，不写完整台词或镜头。

## 执行

Read scene craft 与 schema。提供 2–3 个真实不同场次方案（紧凑单线、对话驱动、行动/旁白混合等），每案说明场次数、节奏、知识承载、优势和代价。用户选择后，为每场登记 scene_id、time budget、location/time、characters、dramatic function、node_ids、fact/knowledge/boundary refs、entry/exit state。

场次不是镜头；不写景别、机位或运镜。

## 输出 schema 与落盘

更新 DRAFT Scene Architecture、coverage ledger 和用户决策；更新 state。

## Hard Stop

```text
╭─ Script Studio · P2 完成 ─╮
│ 选定方案 / 场次数 / node coverage
│ 下一步：P3 Scene Draft
│ NEXT：Next / Back / Edit / Status
╰──────────────────────────╯
```

不自动进入 P3；不得 Skip 方案选择。
