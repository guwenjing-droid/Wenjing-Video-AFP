# Module · Narrative Strategy Library

> 供 P2–P3 按需读取。提供可比较的策略族、适用判据与风险；不提供最终台词、场次或镜头模板。

## 1. 选择原则

策略服务于 Teaching Goal、受众和事实强度，不服务于“看起来像爆款”。每轮筛选 2–3 个显著不同方案：至少一个与材料自然强度匹配，不能默认只给强冲突路线。

评估维度：

- 事实支撑强度
- 教学目标匹配度
- 受众认知门槛
- Hook 可兑现性
- 情绪终点匹配度
- Boundary 风险
- 原创迁移风险（若使用 Reference）

评分只用于方案比较，不是传播成功概率。

## 2. 策略族

### A. 冲突—取舍

- 适用：Truth Lock 存在真实目标冲突、资源约束或利益取舍。
- 核心功能：让观众看到“不能同时得到什么”。
- Payoff：揭示选择及代价，而不是强行分输赢。
- 风险：把制度矛盾人格化成虚构反派；夸大对立。

### B. 悬念—发现

- 适用：材料有信息差、结果与直觉不同，且后文确有证据兑现。
- 核心功能：延迟关键解释，让观众形成可回答的问题。
- Payoff：给出被锁定事实支持的解释或边界化结论。
- 风险：故意隐去必需前提；承诺“真相”却只有观点。

### C. 反差—重估

- 适用：表面现象与机制、短期与长期、局部与整体之间存在已证实差异。
- 核心功能：改变观众的初始分类或判断框架。
- Payoff：展示正确比较维度。
- 风险：制造伪反常识；删掉限定条件以放大惊讶。

### D. 决策—后果

- 适用：管理案例具有明确选项、约束、行动与后果。
- 核心功能：让观众先预测或选择，再观察后果。
- Payoff：复盘决策依据与可迁移知识点。
- 风险：把相关性写成因果；用结果倒推当时决策一定错误。

### E. 共鸣—理解

- 适用：价值在日常困境、角色处境或普遍经验，不需要强反转。
- 核心功能：让观众从“这很熟悉”进入“我终于理解它为什么发生”。
- Payoff：命名机制、给出新的理解或行动视角。
- 风险：用泛情绪取代知识；编造内心独白。

### F. 观察—治愈/余韵

- 适用：案例强度低、关注关系修复、组织日常或细微行为改变。
- 核心功能：通过积累、对照和小变化产生意义。
- Payoff：兑现理解、连接或反思，不强制高潮。
- 风险：节奏无目标；把治愈写成空泛鸡汤。

## 3. Hook Promise 设计

Hook 不是终稿句子，而是承诺结构：

```yaml
hook_id: HOOK-01
promise: "观众继续看将理解/判断什么"
fact_refs: []
knowledge_refs: []
curiosity_question: ""
required_payoff_function: ""
risk: "LOW | MEDIUM | HIGH"
```

合格 Hook：具体、可兑现、与受众相关、不过度泄露结论、不夸大事实。没有有效 Payoff 的 Hook 必须降级或删除。

## 4. 节点功能词库

只使用功能描述，不写镜头：

- Context：建立必要情境与初始状态
- Tension：提出真实约束或未解问题
- Choice：呈现可比较选项
- Escalation：显示后果、成本或信息压力升级
- Discovery/Turning Point：改变理解框架
- Payoff：兑现 Hook Promise
- Reflection/Transfer：把案例机制迁移到观众判断
- Ending/Aftertaste：完成目标情绪并留下行动或问题

节点数量服从材料与目标时长，不硬编码三段式、固定 60 秒或固定镜头数。

## 5. Reference Transfer 使用

Transfer rule 只能影响“机制选择”，不能输入原视频专有内容。使用前回答：

1. 它在 Reference 中的可观察证据是什么？
2. 它是否位于 Artifact 的 analysis_scope 内？
3. 它是否与本项目 Truth Lock 和约束兼容？
4. 去掉原视频角色、事件、措辞和段落后，机制是否仍成立？
5. 在本项目中如何重新实现，而不是复刻？

通过后记录 `transfer_rule_id`、applied_to、adaptation_summary 和 originality check。若答案 4 为否，该规则属于 source-specific，不可迁移。

## 6. 方案输出格式

每个方案包含：strategy、Hook Promise、事实/知识锚、Participation、情绪路径、Payoff、优势、代价、Boundary 风险、Reference 规则（若有）和迁移说明。

## 7. 反模式

- 不把“冲突—反转—高潮”当所有案例的默认骨架。
- 不把策略名写成成品文案。
- 不用不相干的猎奇承诺换取点击。
- 不因 Reference 表现好就跳过本项目适配。
- 不复制参考视频独特顺序、转折和结尾组合。
