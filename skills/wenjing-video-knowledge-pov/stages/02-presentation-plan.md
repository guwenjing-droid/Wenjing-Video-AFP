# P2 · Presentation Plan

*P2 加载：knowledge-evidence-policy、reference-input-policy。*

提供 2–3 个适合内容的方向，比较 POV_IMMERSIVE、EXPLAINER、VISUAL_METAPHOR；组织 Hook → Setup → Layered Explanation → Reveal/Payoff → Ending，不强制固定秒数。

输出 schema：mode、audience promise、narrative nodes、emotion/curiosity curve、knowledge placement、adopted/rejected transfer rules、timing、approval。

Hard Stop：方向不得扭曲 claim。FAST 可 REVIEW，GUIDED/STRICT 等用户批准；不得自动进入 P3。
