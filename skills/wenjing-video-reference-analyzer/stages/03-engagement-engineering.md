# P3 · Engagement Engineering

> 只识别可观察的参与/注意机制，不承诺爆款，也不虚构平台留存数据。

## 执行

1. Read `modules/narrative-engagement-methods.md`。
2. 若有可靠时间码，检查前 3 秒；否则写“开头文本段”，不得伪造秒数。
3. 识别 Curiosity Gap、冲突、共鸣、反差、幽默、爽点、悬念、治愈和互动诱因；不存在则不填。
4. 登记机制出现位置、预期功能、证据锚、confidence 和替代解释。
5. Retention 节点只能写“候选 retention mechanism”；除非用户提供真实数据，否则不能写实际留存效果。

## 完成标准

- 每项机制都能回指材料，不以流行术语堆砌。
- 对预期效果使用限定语，并记录局限。
- transcript-only 不填写音乐、画面、表演、字幕带来的参与效果。

## 输出 schema 与落盘

更新 DRAFT 的 Engagement Engineering 与 Evidence Anchors，更新 state。
