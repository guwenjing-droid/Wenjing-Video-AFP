# P5 · Shootability & Boundary Audit

> 只审计并修订 DRAFT，不创建 Visual Bible 或 Storyboard。

## 审计

1. Truth：每个事实性主张可追溯，新增/冲突事实=BLOCK。
2. Narrative：核心 node、Hook/Payoff、情绪与知识策略无漂移。
3. Boundary：FORBIDDEN=0；CONDITIONAL 均有批准记录。
4. Shootability：动作可执行、空间/时间可理解、对白可说、反应/停顿合理。
5. Coverage：node/fact/knowledge/boundary 达到 100% 或有批准 omission。
6. Responsibility：视觉资产、镜头、运镜、Prompt、模型参数=0。
7. Reference：只保留 Narrative 中已批准 rule provenance，不直接复制原视频。

BLOCK 必须回对应 stage；不得用措辞润色掩盖结构问题。

## 输出 schema 与落盘

完成 DRAFT Audit、issue ledger、coverage 和 readiness；更新 state。
