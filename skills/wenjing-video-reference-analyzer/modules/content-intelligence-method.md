# Content Intelligence Method

## 分析表

1. Audience：核心/次级受众、知识门槛、需求，逐项给 Evidence Anchor。
2. Core Thesis：1–2 句，只保留决定全篇方向的结论。
3. Information Hierarchy：thesis → supporting points → evidence → examples。
4. Evidence Types：data、case、policy、expert claim、demonstration、analogy。
5. Argument Method：案例、数据、比较、因果、政策解读、反证等；分析相关性和跳跃。
6. Domain Link：只登记视频明示或可由内容分类支持的细分领域。

## 数据/案例/政策

保留视频中的原始数值、比较维度、主体、期间和来源表述；若来源没有在材料中出现，写 `source_not_stated`。政策解释分为条文/视频解读/分析判断，不能混写。

## 客观性

只评价内容覆盖、证据选择和论证结构，不诊断创作者动机。绝对化结论、单一样本、过期数据、只列利好/利空均进入 Limitations。
