# Script Schema & Provenance

正式 Script 包含：Contract Header、Upstream Refs、Script Brief、Cast/Voice Placeholders、Scene Architecture、Scene Bodies、Dialogue/VO Ledger、Fact/Knowledge/Boundary Coverage、Production Constraints、Audit、Handoff。

Scene 字段：scene_id、time_budget、location/time、characters、dramatic_function、node_ids、fact/knowledge/boundary refs、entry_state、actions/dialogue/VO、exit_state。

Line 字段：line_id、speaker、exact_text、intent、delivery_note、fact/knowledge refs、duration_estimate。动作字段必须有 actor+verb+object/context；内心感受本身不是动作。
