# Boundary Audit & Local Exemplars

## 四条边界

1. Truth：不为戏剧性新增事实。
2. Narrative：不重选 Hook、结构或结局方向。
3. Visual/Storyboard：场次动作可以写，角色视觉、镜头和运镜不能写。
4. Producer：模型、Prompt、成本和真实生成不能写。

## 历史语料只保留的手感

- “能拍”：把抽象状态转为动作与选择。
- “逐字”：台词成为锁定文本，不让后续模型自由发挥。
- “反应/呼吸”：在冲突或信息落点后给角色真实回应。
- “知识处理”：可隐藏、穿插或结尾升华，但必须服从 Narrative Lock。

不复制旧 Prompt 的固定 60 秒、镜头数、角色/画风、模型、成本或案例文本。
