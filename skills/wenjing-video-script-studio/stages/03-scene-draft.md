# P3 · Scene Draft

> 只写场次、人物行动和暂定台词/旁白，不锁定最终措辞。

## 执行

逐场写地点/时间、在场人物、可观察动作、对白/旁白草稿、反应与呼吸、知识承载和出场状态。每个信息性动作/台词绑定 fact_id 或 knowledge_id；戏剧化细节绑定 boundary_id。心理状态必须转为动作、选择、停顿或说话方式。

保留角色差异，不让旁白解释所有冲突。只写画面中可发生什么，不决定镜头如何拍。

## 输出 schema 与落盘

更新 DRAFT Scene Bodies 与 provenance；维护 unresolved lines 和 coverage；更新 state。
