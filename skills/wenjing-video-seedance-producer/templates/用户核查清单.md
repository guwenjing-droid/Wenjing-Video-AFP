# 用户核查清单

Skill 跑流程，用户用本表监督。低风险步骤可按 control mode 连续执行，但任何 Hard Gate 未满足都必须停。

| 序号 | Skill 应完成的动作 | 用户怎么核查 | 应见落盘文件 |
|---:|---|---|---|
| 1 | 校验 LOCKED Storyboard 与 GREEN PREFLIGHT | decision=GREEN、producer_eligible=true、hash 一致 | `00_project_state.md` |
| 2 | 展示并记录生成后端、模型档、成本模式与运行模式 | 运行者可选；非 Seedance 不由本 Skill 越权执行；真实调用必须 VERIFIED_CURRENT | `generation_manifest.json` DRAFT |
| 3 | 逐镜编译七段 Prompt | 七段齐全且 source refs 可追溯 | `<shot_id>_DRAFT.md` |
| 4 | 锁定 Dialogue/reference/parameter parity | 三类 parity 全 PASS | `<shot_id>_LOCKED.md` + manifest request |
| 5 | 选择 Pilot 并核对分镜预算、预计请求数与成本授权 | ECONOMY 不降质量；scope、最大轮次、成本证据与授权明确 | manifest authorization |
| 6 | 执行或 DRY_RUN 并局部恢复 | DRY_RUN 无假输出；失败只影响指定 shot | manifest attempts + `generation_log.md` |
| 7 | 固化记录并接棒 POSTGEN | 仅 SUCCEEDED 且有实际 output 才 postgen ready | final manifest、log、state |
