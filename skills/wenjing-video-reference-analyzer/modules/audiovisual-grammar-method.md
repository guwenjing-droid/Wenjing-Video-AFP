# Audiovisual Grammar Method

## 观察字段

- Visual：shot scale、composition、camera angle/movement、shot duration、blocking/action、subtitle presence/style、transition、color、lighting、visual style。
- Audio：spoken delivery、music presence/function、sound effects、silence、rhythm。

每项结构：`status`、`observation`、`anchor`、`confidence`、`analytic_inference`。先写观察，后写解释。

## 最低证据

- 景别/构图/站位：至少清晰帧或视频。
- 运镜/镜头长度/转场：连续视频或足够的连续时序帧。
- 表演动作：连续画面；静帧只写姿态。
- 字幕样式：实际画面；transcript 不是字幕视觉证据。
- 音乐/音效/语气：实际可听音频。

本模块不输出拍摄方案、分镜表或生成 Prompt。
